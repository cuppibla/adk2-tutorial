# Build with ADK 2 Orchestration Patterns

This directory contains the files for the **Build with ADK 2 Orchestration Patterns** self-paced lab.

## Overview

Build a Marathon Race Day Coach and learn ADK 2's three orchestration patterns — graph workflows, collaborative agents, and dynamic workflows — one runnable level at a time.

## Folder Structure

- `instructions/en.md`: The instruction manual for the lab.
- `qwiklabs.yaml`: The Qwiklabs metadata configuration.
- `QL_OWNER`: The lab owner/maintainer.
